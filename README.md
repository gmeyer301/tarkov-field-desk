# Tarkov Field Desk

An unofficial Escape from Tarkov companion with a raid journal, quest tracker, interactive maps, and hideout upgrade tracker. The site is static and can be served from the repository root by GitHub Pages.

Field Desk stores your progress and imported stats in your browser. To import in-game totals, find your profile in [Tarkov.dev player lookup](https://tarkov.dev/players), use **Save profile**, and select the JSON under **Import profile** in Field Desk.

Game reference data comes from [Tarkov.dev](https://tarkov.dev/). The [community SVG maps](https://github.com/the-hideout/tarkov-dev-svg-maps) were adapted for ground views and are licensed under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).
